# Защита main

## GitHub

В репозитории [mdk0202-logistics-hub](https://github.com/daniil179/mdk0202-logistics-hub) включено правило для `main`:

- изменения через pull request;
- не менее одного одобрения;
- все обсуждения разрешены перед слиянием;
- обход правил запрещён, в том числе администраторам;
- принудительная отправка и удаление запрещены.

Состояние `protected=true` подтверждено GitHub API. Настройки показаны на скриншотах в [материалах ПР9](../../../../docs/pr09/README.md).

Обязательные автоматические проверки сборки и тестов на GitHub пока не настроены. Локальная сборка и консольные проверки выполнялись отдельно.

## Локальный Git-сервер

Bare-репозиторий защищён обработчиком pre-receive: отклоняются удаление main, force push и прямой одиночный коммит. Разрешён последовательный переход к merge-коммиту выпуска. Результаты сохранены в [журнале Git](../../../../evidence/git/git-verification.txt).

Локальная проверка структуры коммита не удостоверяет личность проверяющего; проверка PR и одобрений на GitHub выполняется правилом защищённой ветки.
